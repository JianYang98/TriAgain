# 일반 PR 본문 작성 기준

- 일반 BE·FE PR에서 변경 이유, 변경 내용, 리뷰에 필요한 검증 근거를 같은 순서로 찾을 수 있도록 본문 기준을 정했다.
- 문구·오타·한 줄 지침처럼 diff만으로 판단할 수 있는 변경에는 이유와 변경만 적는다. 리뷰 판단에 영향을 주는 미실행 검증과 머지 전 조건은 본문에 남긴다.
- 오케스트레이션에서 BE·FE PR을 직접 열 때도 기준이 보이도록 루트 `AGENTS.md`와 BE `.claude/rules/git-convention.md`에 같은 문구를 둔다. 기존 티어별 검증과 머지 절차를 적용한다.
- 본문 기준을 다시 바꾸거나 철회할 때는 두 위치의 문구를 함께 갱신한다.
