## 4. ss 소켓 상태 — 피크 〔측정·ss〕

| 지표 | 최대값 | 발생 시각(KST) | 정렬 런 |
|---|---|---|---|
| `acceptQ` (완료연결 큐 점유/한도) | **101 / 100** | 12:15:14 · 12:15:50 · 12:16:29 · 12:17:16 | vu300·vu400·vu500·vu700 |
| `SYN-RECV` (half-open) | **101** | 12:14:39 | vu200 |
| `SYN-RECV` 잔여 | 7 | 12:17:17 | vu700 |
| `ESTAB` (establish 세션) | **694** | 12:17:16~18 | vu700 |
| `TIME-WAIT` | 2 | 산발 | — |

- **acceptQ가 한도 100을 초과(101)한 순간**이 ListenOverflows 움직임 시각(vu300·400·500·700)과 정확히 일치.
- **SYN-RECV 101(vu200)**은 SYN 큐가 half-open으로 가득 찬 순간 = SyncookiesSent 폴백 시작 시각과 일치.
- acceptQ>0 샘플은 4건뿐 — ss 샘플링(~3.2/s)이 1초 미만 버스트를 부분 포착(over/underflow는 sub-second라 5개 버스트 중 4개만 스냅). **한도 도달 사실은 확인, 총량은 nstat Δ가 정본.**
- **ESTAB 694 (vu700)**: 700 VU 중 694 세션이 동시에 establish까지 도달(나머지는 드롭/미수립).
- 〔파생〕 **ESTAB 피크 = VU + 1 패턴**: vu20~vu500까지 매 런 정확히 VU+1(21·51·101·201·301·401·501 — 모니터링 커넥션 1 포함). **vu700만 694 = 701 − 7** — 결손 7이 곧 k6 드롭 7 (§5 교차검증 여섯째 소스).

## 7. 〔분석〕 — 층 분리 결론 (측정값 아님)

> §0~§6과 분리. 서버측 실측이 있으므로 이전 k6 보고서가 유보했던 판정을 여기서 확정한다.

1. **드롭의 층 규명 (k6 보고서 caveat 해소)**: 이전 `0703_비관락5차-결과.md` §9는 "vu700 드롭 7이 SYN 재전송층인지 accept 큐 오버플로층인지 판별 불가"라 했다. **본 로그로 확정**: 드롭 7건은 **SYN 쿠키 검증 실패층**(`SyncookiesFailed +7` = `AttemptFails +7` = ss `SYN-RECV` 잔여 7 = ss `ESTAB` 결손 7 = k6 `connection reset by peer` 7 = `join_dropped` 7 = Prometheus acquire 미획득 7, §5 7개 관측 일치). accept 큐 오버플로층이 아니다.

2. **두 병목층이 동시에, 그러나 서로 다른 증상으로 발현**:
   - **accept 큐 오버플로(`ListenOverflows +2239`, vu300~)**: 대량이지만 SYN 쿠키 + 클라이언트 재전송으로 **회복** → k6 드롭이 아니라 **지연(p95 상승)으로 발현**. vu500 단일 요청 5065ms 이상치도 이 회복 지연과 정합적.
   - **SYN 쿠키 검증 실패(`SyncookiesFailed +7`, vu700만)**: 회복 못한 7건 → **k6 드롭**. 유일하게 영구 실패한 층.
   - `TCPBacklogDrop=0`·`ReqQFullDrop=0`: 커널 직접 드롭 경로는 미발동. 포화가 전부 쿠키/재전송으로 흡수된 뒤 극소수만 최종 실패.

3. **t3.micro 연결계층 천장 재확인 (락 무관)**: 포화 카운터(Overflows·Syncookies·SynRetrans)는 전부 **TCP 연결 수립 계층**이다. `join_5xx=0`·`join_success=10`(전 8런)이므로 **애플리케이션/락 정합성은 완벽**하고, vu700 드롭은 서버 스펙(accept 큐 100·SYN 큐)의 커널 천장이다. 메모리의 t3.micro 버스트 천장 관측과 일치.

4. **층 시작 임계 (이번 런)**: SYN 큐 포화 **vu200**부터 · accept 큐 오버플로 **vu300**부터 · 영구 드롭 **vu700**에서 처음. vu20~vu100은 무포화(모든 포화 카운터 Δ0).

5. **드롭은 전략 판별 지표가 아님(재확인)**: SyncookiesFailed는 서버 스펙·순간 SYN 폭주에 좌우돼 런마다 편차가 크다(0702=16, 0703=7). 전략/차수 비교는 드롭이 아닌 **완료 요청 p95**로만.
