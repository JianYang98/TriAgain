## 읽는 포인트 〔분석〕

1. **층 진입 계단이 6차판으로 바뀜**: 5차 "무포화(≤vu100) → 쿠키(vu200~) → 오버플로(vu300~) → 영구드롭(vu700)" → 6차 "무포화(≤vu200) → SYN 큐 순간 포화·쿠키(vu300 한 번뿐, +41 ≈ 300−256) → **SYN-ACK 재전송 흡수(vu400~700)** → 오버플로·영구드롭 층 미발동". vu400 이후 쿠키가 다시 0인 것은 재전송 사다리가 도착을 시간축으로 흩어 SYN 큐가 256을 다시 못 채웠기 때문.
2. **Recv:Sent 관계가 5차와 반대**: 5차 Recv(3,395) ≫ Sent(1,514) = accept 큐 만석으로 쿠키 ACK가 버려져 재전송마다 재검증된 루프의 흔적. 6차 Recv(+39) < Sent(+51) = 발급 쿠키 51개 중 39개만 ACK로 회수, 나머지 12개는 유실됐거나 클라이언트 SYN 재송으로 일반(스테이트풀) 경로로 갈아타 수립.
3. **검증실패 ≠ 드롭 (반례 확보)**: 5차 vu700은 Failed +7 = 드롭 7 등식이 7개 관측으로 일치했지만, 6차 vu300의 Failed +3(OutRsts +3과 쌍)은 k6 300건 전건 정상 완료(checks 100%, 드롭 0) — 등식이 항상 성립하지 않는다. 기전 미확정(재수립 회복 또는 종료 시점 잔류/중복 ACK 추정), 영향 0.
4. **SynRetrans +1,824(런 귀속분)가 이번 스윕의 유일한 대량 카운터** — k6 `http_req_blocked` 초 단위 사다리(vu700 max 15.3s = 1+2+4+8 백오프)와 같은 창. 유실층 자체는 세션 노이즈이며 accept-count 귀속 금지 — 판정 근거는 `0703_비관락-5차6차-비교.md` §9.4.
