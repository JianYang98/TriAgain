## §0. 비교 정의

- **비교축**: A9(Serial·off) ↔ A11(G1·off) / A10(Serial·on) ↔ A12(G1·on)

## §5. GC 대조 (핵심)

**자연 GC (off 블록)**

| | Serial A9 | G1 A11 |
|---|---|---|
| 자연 young | **20** (Copy) | **10** (Evac Pause) |
| 자연 Major/Full | **1** (236ms · vu500 런 정중앙) | **0** |

**게이트 GC (on 블록)**

| | Serial A10 | G1 A12 |
|---|---|---|
| young (Copy/Evac) | **13** | **7** |
| 게이트 Full GC 횟수 | 8 | 8 |
| 게이트 pause 범위 | 165~224ms | 119~194ms |
| 힙 리셋 baseline | 48~53MB | 42~50MB |
| 자연 Major/Full | 0 | 0 |

- 게이트에 의한 young 변화: Serial **20→13 (−35%)** / G1 **10→7 (−30%)**.
- 주1: `Copy`(Serial)와 `Evacuation Pause`(G1)는 서로 다른 컬렉터의 young 수집 — 횟수 직비교 시 단위 이질.
- 주2(사실): 같은 off·같은 GC라도 전략 따라 young 총량 상이 — G1 off young PESS 24(C17) vs COND 10(A11) / Serial off young PESS 15(C15) vs COND 20(A9).
