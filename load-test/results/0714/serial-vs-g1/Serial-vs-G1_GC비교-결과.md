# Serial(0713) ↔ G1(0714) GC 비교 — 결과 (사실 적시)

> 이 문서는 **사실·숫자·출처만** 담는다. 해석은 `Serial-vs-G1_GC비교-전격분석.md` 참조.
> 0714 C17C18 결과서 **미완 과제 ④**(G1↔Serial 완료 p95 정면 비교)의 실체화.

## §0. 비교 정의

- **비교축**: C15(Serial·off) ↔ C17(G1·off) / C16(Serial·on) ↔ C18(G1·on)
- **단일 변수 = GC 컬렉터**. 그 외 환경 전 항목 일치(아래 표).

| 항목 | Serial (0713 · C15/C16) | G1 (0714 · C17/C18) |
|---|---|---|
| 환경 | Docker `triagain-loadtest` | 동일 |
| 박스 | t3.micro · 13.125.7.72 | 동일 |
| RDS | test PG17 · t4g.micro | 동일 |
| 락 전략 | PESSIMISTIC | 동일 |
| accept-count | 256 | 동일 |
| 힙 | ergonomic ~256MB (no -Xmx) | 동일 |
| VU 셔플 | 20→400→50→300→100→500→200→700 | 동일 |
| 케이던스 | 2분 균일 | 동일 |
| 블록 설계 | off 8런 → on 8런 | 동일 |
| **GC 컬렉터** | **Serial** (ergonomic default) | **G1** (`-XX:+UseG1GC` env 주입) |
| GC 문자열 | `Copy`(young) · `MarkSweepCompact`(full) | `G1 Young Generation/G1 Evacuation Pause` · `G1 Old Generation` |
| JVM 기동 | 07-13 15:21:26 KST | 07-13 23:35:05 KST |
| 워밍업(버림) | 4런 | 3런 |

## §5. GC 대조 (핵심)

**자연 GC (off 블록)**

| | Serial C15 | G1 C17 |
|---|---|---|
| 자연 young | **15** (Copy) | **24** (Evac Pause) |
| 자연 Major/Full | **1** (192ms · vu700 런 정중앙) | **0** |

**게이트 GC (on 블록)**

| | Serial C16 | G1 C18 |
|---|---|---|
| young (Copy/Evac) | **13** | **8** |
| 게이트 Full GC 횟수 | 8 | 8 |
| 게이트 pause 범위 | 141~245ms | 123~231ms |
| 힙 리셋 baseline | 53~58MB | 56MB |
| 자연 Major/Full | 0 | 0 |

- 게이트에 의한 young 변화: Serial **15→13 (−13%)** / G1 **24→8 (−67%)**.
- 주: `Copy`(Serial)와 `Evacuation Pause`(G1)는 서로 다른 컬렉터의 young 수집 — 횟수 직비교 시 단위 이질(전격분석 §6에서 다룸).
