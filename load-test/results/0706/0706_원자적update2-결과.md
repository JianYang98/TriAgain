## 9. 분석 〔분석〕

1. **이번 세션의 확정 성과는 드롭 등식 재마감이다.** AttemptFails=드롭 4/4, 쿠키 산수, ESTAB 공식 8/8, CR002 8/8 — 07-04 A1의 6중 일치가 관측 풀셋으로 재현됐다. "드롭=수립층, 락 무관"은 이제 7세션 연속.
2. **드롭 개시 VU를 정하는 건 backlog라는 그림이 강화됐다**: 256인 세션(C7·C9·A2)은 전부 vu300 개시, C10(미상)만 vu500. `acceptQ=0/4096` 관측은 운영 박스(도커 프록시)로 판명돼 C10 단서에서 제외(👤 확인) — C10 실효 backlog는 재현 측정(기동 명령 기록 + ss)으로만 닫힌다.
3. **완료 p95의 A2 열세는 이 데이터만으로 전략 우열로 읽으면 안 된다.** 07-04 통제쌍(A1↔C7, 같은 backlog·같은 밤)은 조건부 우세(−180~−334ms)를 냈는데, 이번 C10↔A2는 backlog가 다르고(§8-1) 시각대도 다르다(22시대 vs 새벽 1시대, C10 종료 후 4번째 스윕째 밤). 후보였던 (a) "전략이 실제로 CONDITIONAL이 아님"은 **§7.4 acquire 지문으로 기각** (383ms 무사다리 = 조건부). 남는 후보: (b) **서버/DB 상태 드리프트 — RDS(버스트형이면) CPU 크레딧 소진 미확인 👤** (EC2 크레딧은 만탱크 선례 있으나 RDS는 한 번도 확인 안 함; 하루 4스윕째 새벽 세션이라 의심 타이밍. 조건부의 병목은 풀이 아니라 DB 원자 UPDATE 왕복이라, DB가 느려지면 acquire엔 안 보이고 409 레이턴시에 직격 — 관측과 정합), (c) 새벽 시간대 경로 변화 — 기저 RTT 동급이라 약함. **판정: 전략 우열 갱신은 보류, 07-04 A1↔C7 통제쌍이 여전히 정본. 처방 = 크레딧 확인 후 같은 backlog로 C↔A 교차 재측정.**
4. vu300 완료 p95(2,009)가 vu400(1,700)·vu500(1,618)보다 높은 역전은 C10 §8-2의 도달수 회계와 방향은 같으나(도달 266 vs 318 vs 353) 단조가 아니다 — 도달수 모델이 A2에서는 vu300이 이상점 (첫 드롭 런 + 쿠키 첫 발동 런의 과도 상태 〔추정〕).
5. **정합성 요지부동**: 8런 success=10 정확. FAIL 4런 전부 수립층 드롭.
