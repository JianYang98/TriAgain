## 6. 3차 서버측 실측 요지 (로컬 Prometheus PromQL) 〔측정·PromQL〕

> **3차만** 로컬 Prometheus(:9090) PromQL 직접 조회로 서버측을 실측했다(창 KST 20:22:30~20:29:00). 1·2차는 동급 서버측 실측이 없고 Grafana 스크린샷(5s 눈대중)뿐 → 아래는 3차 단독 팩트다. **워터마크**(`*_seconds_max`)는 세션 진짜 최고점, **5s게이지**는 5s 표본 최대(하한).

| 지표 | 실측 | 종류 | 사실 |
|---|---|---|---|
| `hikaricp_connections_active` (max) | **10** | 5s게이지 | 풀 상한 = 100% 사용 |
| `hikaricp_connections_idle` (min) | **0** | 5s게이지 | 풀 고갈 |
| `hikaricp_connections_pending` (max) | **37** | 5s게이지(하한) | 커넥션 대기 ≥37건 |
| `hikaricp_connections_acquire_seconds_max` | **0.758 s** | 워터마크 | 커넥션 획득 대기 최고 **758 ms** |
| `tomcat_threads_busy_threads` (max) | 48 / 200 | 5s게이지 | 워커 여유 |
| `system_cpu_usage` (max) | 0.295 (29.5%) | 5s게이지 | CPU 여유 |
| `sum(jvm_memory_used_bytes{area="heap"})` | ≤ 102.4 MiB | 5s게이지 | 힙 여유 |
| `jvm_gc_pause_seconds_max` | 0.016 s (16 ms) | 워터마크 | GC 여유 |
| accept-queue `Send-Q`(=`acceptCount`) | 100 (상한 고정, 오버플로 아님) | 서버 ss + nstat | vu200·300 드롭은 `ListenOverflows=0`·`TCPSynRetrans`↑ = **SYN 수립 실패**(§드롭 계층) |

- **3차 병목 = DB 커넥션 풀(10)**: 버스트에서 active=10 · idle=0 · pending≥37로 완전 포화, 획득 대기 최고 **758 ms**. 서버측 최장 join 요청 935 ms의 대부분이 이 대기.
- **여유 자원**: Tomcat 워커 48/200 · CPU <30% · 힙 ≤102 MiB · GC ≤16 ms — 스레드·CPU·메모리·GC는 병목 아님.
- **드롭 계층 구조 (당일 nstat 실측으로 정정)**: 3차 드롭(k6 83·98)은 **accept 큐 오버플로가 아니다** — `nstat` 시계열에서 `ListenOverflows=0`·`ListenDrops=0`, 드롭과 1:1로 맞는 건 `TCPSynRetrans` 스파이크(20:25:22 +83·20:27:38 +100) = **TCP 핸드셰이크 수립 실패**(서버 SYN-ACK 재전송). ⚠️ 06-23 배치는 accept 큐 오버플로였음 → 커널 층이 런마다 다름. **1·2차 drop은 서버측 실측 없어 미확정**(3차 결론을 그대로 이월 금지).

## 7. 관측된 차이 (사실만) 〔측정〕 〔파생〕

- 정합성 카운트(succ=10 · 5xx=0 · succ+full+drop=reqs)는 **3회차·전 VU 동일하게 성립**.
- `drop > 0` 최초 등장 VU: 1차 = vu300 / 2차·3차 = vu200 (2·3차가 더 낮은 VU부터 드롭 관측).
- vu300 `drop`: 1차 99·64 / 2차 97 / 3차 98 — 네 런 모두 >0, 64~99 편차. 1차 문서는 이를 "연결계층 재실행 편차 지표"로 규정.
- vu300 p95: 1차 785.3·760.5 / 2차 1220.2 / 3차 1080.3 (회차 간 절대값 상이 — 원인 귀속 안 함).
- `conflict`(join_conflict) 카운터는 3회차 summary 전부 미방출(n/a).
- 서버측 실측은 3차만 보유(병목=DB 커넥션 풀, acquire 758ms) — 1·2차는 동급 데이터 없음.
- ※ 위 절대값 차이의 **원인 귀속·회차 우열 판정은 하지 않음** — §0 "측정일 간 절대 비교 무효" 경고 참조.
