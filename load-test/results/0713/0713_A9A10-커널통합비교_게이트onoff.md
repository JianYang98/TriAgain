# 0713 A9↔A10 커널 통합 비교 — pre-GC 게이트 off↔on · nstat·ss·tcpdump

> 출처: **〔측정〕** `nstat-ts-183348-A9A10.log` · `ss-state-183414-A9A10.log` · `tcpdump-183429-A9A10.pcap`(A9·A10 공용 캡처 1벌) · `A9/run-log-A9.md` · `A10/run-log-A10.md`. **〔파생〕** 계산. 세션별 정본 = 자매 문서 2본(하단 참조). 해석·추정·귀속 판단은 §7에 격리.
> 본 문서는 **두 세션의 커널 사실을 나란히 대조**할 뿐, 차이를 **게이트 효과로 귀속하지 않는다**(§0·§7 필독).

## 0. 비교 설계 & 교락 경고 〔측정·설계〕

**동일 조건 (통제된 변수)**

| 항목 | A9 = A10 |
|---|---|
| 락 전략 | CONDITIONAL(원자적 UPDATE) — 동일 |
| accept-count | 256 — 동일 |
| VU 스윕·실행순 | 20·400·50·300·100·500·200·700 — 동일 |
| 서버 | Docker 컨테이너 `172.17.0.2:8080` · 동일 JVM(**18:22:49 기동**) |
| k6 소스 | `220.116.188.182` — 동일 |

**유일 의도 변수**: pre-GC 게이트 — **A9 = PRE_GC off(무게이트 arm)** · **A10 = PRE_GC on(게이트 무장, arm=on)**.

**⚠️ 3중 교락 — 커널 차이를 게이트로 귀속 불가**

1. **블록 순서 완전 교락**: A9(off)가 **항상 먼저**, A10(on)이 **항상 나중**(19:05 → 21:13, 같은 밤). on-first 실험 부재 → 게이트 효과와 순서 효과 분리 불가.
2. **JVM 성숙 교락(실증)**: 같은 JVM에서 A10은 A9보다 14런+워밍업 뒤. GC 카운터로 실증 — **Copy GC A9 구간 27→54 vs A10 구간 101→119**. A10은 JVM 수명 후반(JIT·RDS 캐시 성숙).
3. **게이트 작용 층위**: pre-GC 게이트는 **앱 힙 GC(지연 측정 정합)** 를 건드릴 뿐, **TCP 수립 층(SYN큐·쿠키·드롭)은 게이트 경로 밖**. 즉 아래 커널 차이는 게이트가 물리적으로 개입하는 지점이 아니다.

→ **결론(경계)**: 아래 표의 A9↔A10 차이는 **사실**이나, 그 원인은 순서·성숙·클라 도착률 변동이 게이트와 뒤섞여 **본 데이터로 분해 불가**. 게이트의 목적(지연에서 GC 잡음 제거)은 **k6 지연**(`0713_CONDITIONAL-A9A10-결과.md` §6)에서 평가하며, 본 커널 비교의 소관이 아니다.

## 6. 발현형 요약 〔파생〕

- **공통**: SYN큐→쿠키 경로(오버플로 0) · inRST=drop · outRST=CkFail · 쿠키↔AttemptFails 1~2초 선행 · 최대재전송 런 pcap 발산.
- **A9(off) 고유**: drop = AttFail+EstRst(EstRst 관여) · 워밍업 SynRtx+36 · vu300 쿠키만·무드롭 · CLOSE-WAIT 관측 · 드롭 개시 vu400.
- **A10(on) 고유**: drop = AttFail 단독(EstRst 0) · SynRetrans 2.3배 · vu300 드롭 6+SynRtx 258(지연흡수) · vu700 CkFail 333>drop 257(초과76) · ESTAB 도달+2 · FIN-WAIT-2 관측 · false start+워밍업 3런 · arm=on GC지문(System.gc 4→12) · 드롭 개시 vu300.

## 7. 이 비교가 확정하지 않는 것 〔분석 경계〕

- **A9↔A10 커널 차이의 게이트 귀속** — §0의 3중 교락(블록순서·JVM성숙·게이트 층위)으로 **불가**. 드롭·재전송·쿠키 차이는 게이트가 개입하지 않는 TCP 수립 층이며, on 블록이 항상 나중이라 순서/성숙과 분리 안 됨. 확정 경로 = **on-first 실험**(러너 블록 순서만 교체, 결과서 §7 최우선 후속).
- **A10 > A9 드롭·SynRetrans 증가의 실체** — 성숙은 감소를 예측하므로 증가는 클라 도착률/타이밍 변동 등 미측정 요인. 본 데이터로 분해 불가.
- **ESTAB 도달+2의 "+2" 실체**(§5) — arm=on 여분 커넥션 후보이나 pcap 플로우 귀속 미수행.
- **재전송 발산(A9 vu500·A10 vu700)** — 쿠키 ISN 회전 추정, 미확정.
- **vu700(A10) 이중 RST 76·vu300(A10) 지연흡수 258** — 정식 pcap 플로우 페어링 미수행.
- **게이트가 k6 지연에 미친 효과** — 본 문서 소관 밖(`0713_CONDITIONAL-A9A10-결과.md` §6가 정본, 그쪽도 순서 교락으로 "게이트가 p95 개선한다 주장 불가"로 결론).
