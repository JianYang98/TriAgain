## 2. 드롭 플로우 전수 추적 (316개) 〔측정〕

전 플로우 1,571개 중 RST 종료 316개 = k6 드롭 316과 총량·런별(34/114/168) 모두 정확 일치.

### 시퀀스 패턴 (316개 전수 분류)

| 개수 | 시퀀스 |
|---|---|
| 262 | In S → Out S.(ISN₁) → In S(재전송) → Out S.(**ISN₂**) → **Out R**(seq=ISN₁+1) → Out S.(ISN₂ 재전송) → In R |
| 37  | 위와 동일하되 클라 SYN 3회 (In S ×3) |
| 7+7+2+1 | 위 두 형의 SYN-ACK 재전송 횟수/이중 Out R 변형 |

**316/316 공통 불변식 3개:**
1. **SYN-ACK ISN이 정확히 2종** — 첫 SYN에 ISN₁, 재전송 SYN에 **다른** ISN₂가 응답됐다. 반면 RST 없이 완료된 재전송 플로우(381개)는 재전송 SYN-ACK이 전부 **동일 ISN**(단순 재전송). ISN 2종 여부와 드롭 여부가 316/316·381/381 완전 대응.
2. **Out RST seq = ISN₁+1** (316/316) — 서버 RST는 항상 첫 번째 SYN-ACK의 시퀀스 공간을 종료한다.
3. 마지막은 서버의 ISN₂ SYN-ACK 재전송(~1s 백오프)에 대한 **클라 In R** — 플로우 종료 시각은 첫 SYN 대비 mean 1.36s(min 1.07 / max 7.34).

### RST 타이밍 〔측정〕

- 첫 RST까지(첫 SYN 대비): 50~100ms 32건 · **100~300ms 277건** · 1s+ 7건 (mean 189ms) — **즉사형**(C10의 ~0.5s 지연형·07-03 6차의 지연흡수형과 구분되는 분포).
- Out RST가 런 버스트 첫 초에, In RST가 다음 초에 몰림(예: vu500 → Out 201@00:06:42, In 157@00:06:43).

## 3. 이중 Out RST = SynFailed 잉여의 실체 〔측정·파생〕

- 플로우당 Out RST: 1개 281플로우 · **2개 35플로우(전부 vu500)**. vu300·vu400은 0건.
- Out RST 총량 = 34/114/**203** = nstat SyncookiesFailed 버스트(34/114/**203**) = nstat OutRsts 버스트(34/114/203) — **3채널 완전 일치**.
- **vu500 SynFailed 잉여 35 = 이중 Out RST 플로우 수 35** — C11에서 규명한 "SynFailed 잉여=이중 RST" 메커니즘의 2번째 관측(오차 0).
- In RST(클라 RST) = 34/114/**168** = k6 드롭 = nstat AttemptFails — 드롭 1건당 In RST 정확히 1개.

## 4. SYN 재전송 〔측정〕

- 클라 SYN 재전송: 1회 642플로우 · 2회 55플로우(전부 vu500 창). **재전송 간격 전량 120ms 미만**(mean 78ms, 752건 전수) — 표준 RTO 백오프(1s/2s/4s)와 다른 값. 클라(macOS k6)의 재전송 동작이라는 것 외 원인 미기록.
- 서버 SYN-ACK 재전송(동일 ISN, 762건): ~0.1s 370건 + **1s→2s→4s 배수 백오프**(1.0~1.1s 316건, 2.1s 17건, 4.1s 8건). 최장 플로우는 +1.17/+3.25/+7.33s 3회 재전송 후 클라 RST(포트 4186 전문 §2).

**교차 확정 사실:**
- ss의 **SYN-RECV=1 지속(00:04:02~00:05:06, 64초) = 위 45.198.224.5 미완성 플로우 1건** — SYN-ACK 재전송 스케줄(마지막 00:04:33 + 최종 대기)과 소멸 시각이 정합. k6 무관.

- **nstat SynRetrans 램프 +1,950(00:04:01~00:05:36)은 이 pcap에 없다** — 해당 구간 pcap 패킷은 위 45.198.224.5 관련 7개(SYN-ACK 재전송 ≤6회분)가 전부. 램프의 나머지(~1,944건)는 **8080 포트 캡처 범위 밖**(nstat는 시스템 전역 카운터). 주체 특정은 이 세션의 채널로는 불가 — 미확정으로 남긴다. k6 런 결과와의 무관성은 §1(vu100 클린 100/100)으로 확인됨.

## 7. 관측이 시사하는 것 / 확정하지 않는 것 〔분석 — 사실 아님〕

- 드롭 시퀀스(ISN₂ 등장 = 재전송 SYN에 다른 ISN 응답 → 첫 ISN 공간에 RST)는 nstat의 쿠키 지문(ReqQFullDoCookies→SyncookiesFailed)과 시각·수량이 동행한다. "SYN큐 포화 → 재전송 SYN에 쿠키 SYN-ACK(ISN₂) → 첫 SYN-ACK(ISN₁) 기준으로 완성하려는 핸드셰이크가 쿠키 검증 실패 → RST" 해석과 **모순되는 관측은 없다** — 단 ACK 패킷이 필터로 빠져 있어(§0) 핸드셰이크 완성 방향은 패킷으로 직접 확인 불가. 확정 아님.
- 클라 SYN 재전송 <120ms의 원인(OS/k6 설정)은 이 캡처만으로 특정 불가.
- §5 램프 주체 미확정.
