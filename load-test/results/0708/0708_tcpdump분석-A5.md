## 2. 드롭 플로우 전수 추적 (514개) 〔측정〕

전 플로우 2,272개 중 RST 종료 514개 = k6 드롭 514와 총량·런별(110/203/10/191) 모두 정확 일치.

### 시퀀스 패턴 (514개 전수 분류) — shape = (In-SYN 수, ISN 종수, SYN-ACK 수, Out RST 수, In RST 수)

|---|---|---|
| 414 | (2, 2, 3, 1, 1) — 기본형: In S → Out S.(ISN₁) → In S(재전송) → Out S.(**ISN₂**) → **Out R**(=ISN₁+1) → Out S.(ISN₂ 재전송) → In R | vu400 105 · vu700 111 · vu300 10 · vu500 188 |

| 4   | (3, 2, 4, 1, 1) — In-SYN 3회, RST는 1회 | 전부 vu700 |

**514/514 공통 불변식 (C12에서 확립된 2종 재현):**
1. **SYN-ACK ISN이 정확히 2종** — 첫 SYN에 ISN₁, 재전송 SYN에 다른 ISN₂ (514/514). 반면 RST 없이 완료된 재전송 플로우 **595개는 전부 단일 ISN** (595/595). ISN-2종 여부 ↔ 드롭 여부 완전 대응 — **2세션 연속 예외 0**.
2. **Out RST seq = ISN₁+1** (514/514) — 서버 RST는 항상 첫 SYN-ACK의 시퀀스 공간을 종료.

## 3. 이중 Out RST = SynFailed 잉여의 실체 〔측정·파생〕

- 플로우당 Out RST: 1개 430플로우 · **2개 84플로우(전부 vu700)** · 3개+ 0.
- **vu700 SynFailed 잉여 84 (287−203) = 이중 Out RST 플로우 수 84** — C11에서 규명·C12 vu500(+35)에서 재확인된 메커니즘의 **3번째 관측, 오차 0**.
- Out RST 총량 = 110/**287**/10/191 = nstat SyncookiesFailed 버스트 = nstat OutRsts 버스트 — **3채널 완전 일치** (세션 합 598도 3면 일치).
- 이중 RST 84건 전수: 두 Out RST의 **seq가 84/84 동일**(=같은 RST의 재전송), 간격 mean 30.5ms (min 5.5 / max 36.0).
- 이중 RST는 전부 In-SYN 3회(재전송≥2) 플로우 — vu700의 3회-SYN 드롭 플로우 88건 중 84건이 이중, 4건은 단일 ("재전송≥2 ↔ 이중RST" 대응에 이번 세션 예외 4건).
- In RST(클라 RST) = 110/203/10/191 = k6 드롭 = nstat AttemptFails — 드롭 1건당 In RST 정확히 1개.

## 7. 관측이 시사하는 것 / 확정하지 않는 것 〔분석 — 사실 아님〕

- 드롭 시퀀스(재전송 SYN에 다른 ISN₂ 응답 → ISN₁ 공간에 RST)는 nstat 쿠키 지문(ReqQFullDoCookies→SyncookiesFailed)과 시각·수량 동행 — C12 §7의 "SYN큐 포화 → 쿠키 SYN-ACK(ISN₂) → ISN₁ 기준 핸드셰이크 완성 시도 → 쿠키 검증 실패 → RST" 해석과 **모순되는 관측은 없다**. 단 ACK 패킷이 필터로 빠져 있어 핸드셰이크 완성 방향은 직접 확인 불가 — 확정 아님.
- 클라 SYN 재전송 <120ms대(macOS k6)의 원인, 서버 SYN-ACK 재전송 간격의 이봉 구조(§4) 임계 — 이 캡처만으로 특정 불가.
- vu400·vu700의 nstat SynRetrans ↔ pcap SYN-ACK 재전송 불일치(−16/−115)의 원인 — 미판정.
- 스트래글러 성공 플로우 2건(00:32:19.795·00:40:39.788, k6 클라 IP)의 주체 — k6 러너 사전/사후 커넥션 여부 미확정(C12 vu300 창 선행 플로우 1건과 유사 형태).
- §5 램프 주체 미확정. 이중 RST 84건이 "같은 seq의 재전송"으로 나타난 커널 경로 — 미확정.
