## 3. 사실 목록 〔측정·파생〕

1. **정합성(락)은 전 구간 완벽** — `success=10`(정원 정확) · `conflict=0` · `5xx=0`, 8/8런 예외 없음 (k6·앱로그 ERROR 0건·Prometheus 5xx 0 3면 일치).
2. **409 = 1,676, 3채널 정확 일치** — k6 full 합계 = Micrometer(`status=409,error=none`) = 앱로그 CR002 카운트, 셋 다 1,676 0오차. 런별 CR002도 도달−10과 **8/8 일치**(10/280/487/40/280/90/299/190). `409+IOException` 0건 = **유령 409 미발생 2연속**(C12에 이어).
3. **드롭은 vu300부터** (10/110/191/203 @ 300/400/500/700) — **실행 순서와 무관**(vu200 8번째 0드롭, vu400 2번째 110). 개시 VU=300은 C11·C12와 같은 층, vu300 값 10은 시리즈 드롭 런 중 최소(C12 34·C11 40).

5. **ESTAB 피크 = 도달 + 1(베이스라인), 8/8 정확** (ss) — 21/291/498/51/291/101/310/201 = 각 런 완료요청수+1.
6. **acceptQ 실사용 76/256 @00:31:49(vu700 창) 1표본** — 시리즈 **2번째** 실사용 관측(A4 87/256 이후), C12는 전 구간 0. ListenOverflows는 0 유지.
7. **SYN-RECV 고원 = 드롭수, 4/4 정확** (ss: 110/203/10/191) — A4에서 발견된 예측 채널 재확인.

9. **완료 p95 ≥ 드롭포함 p95, 재계산 가능한 드롭 런 2/2** (vu300 1405.1>1400.4 · vu400 2610.9>2594.3) — 드롭=빠른 죽음이 집계를 끌어내리는 기전 재확인.
