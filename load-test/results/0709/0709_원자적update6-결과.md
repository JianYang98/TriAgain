## 2.4 유령409(409+IOException) 〔측정·앱로그·패킷〕

- **k6 409 합 1,553 · 서버 CR002 로그 합 1,556 → 차이 3.** 전부 **vu700**에서 발생.
- 서버 Micrometer 기준 409(error=none) 1,553 = k6 409 합과 일치, **409+IOException 3건**(전부 vu700, 첫 08:58:55Z)이 별도로 존재한다(`http_join_ioerror_raw` 최종 누계 3, prometheus-a6 정본).
- **패킷 레벨 독립 확증**: vu700 드롭플로우 241 − ISN-2종(쿠키) 플로우 238 = **3**. 이 3건은 쿠키 재전송이 아닌 **단일 SYN-ACK ISN**이며, 클라 RST의 seq가 첫 SYN seq + 385(≈384B HTTP 요청 데이터가 실제로 전송됨)로, 커넥션이 수립되고 서버가 요청을 획득·처리(409)했지만 응답이 클라에 도달하지 못한 사례로 판단된다. 반면 쿠키-드롭(238건)은 클라 RST seq = SYN seq + 1(데이터 0, 핸드셰이크 미완성)이다.
- **3채널 확증**: k6−CR002 차(3) · Micrometer 409+IOException(3) · pcap "seq+385 데이터전송 드롭플로우"(3) — 전부 vu700, 클라 RST 동일 시각 17:58:52.305.
- **락 정합성에는 무해**(success=10 · 5xx=0 유지).
