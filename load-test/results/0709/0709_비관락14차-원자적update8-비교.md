# 크루 가입 러시 — 비관락 14차(C14) ↔ 조건부(원자적 UPDATE) 8차(A8) 비교 · 2026-07-09 (KST)

> **한 줄 결론**: 병목 층(HikariCP acquire)과 서버측 처리시간(`http_server_requests_seconds`) 전 구간에서
> **조건부(A8)가 비관락(C14) 대비 우세** — 서버측 완료 p95 7/7(1.48~2.52×), acquire p95 8/8(1.75~3.68×).
> 락 정합성은 양쪽 완벽. 이번 페어로 조건부 우위가 **또 한 번 독립 재확인**된다.

---

## 0. 비교 성격 & 캐비앗 〔필독〕

- **지정 통제쌍(統制쌍)이 아니다.** 전략 정본 쌍은 07-04 **A1↔C7**, 같은밤 버킷 페어는 **C12↔A5·C13↔A6**.
  C14↔A8은 같은 밤 ~1시간 간격·같은 t3.micro·같은 accept-count 256·같은 8런 완전스윕·**동일 셔플 실행순**이라
  **정황 유효한 보조 비교**지만 정본 쌍은 아니다.
- **실행순이 완전히 동일**(20→400→700→50→300→100→200→500) → 콜드/웜 교란이 양쪽 정렬됨(vu400=둘 다 2번째런 콜드JVM,
  vu700=둘 다 3번째런, vu500=둘 다 마지막 웜). 이 비교의 강점.
- **드롭은 이 문서에서 비교하지 않는다**(요청에 따라 생략). 드롭은 t3.micro TCP 수립 천장(즉사 쿠키실패형)으로
  **전략무관 노이즈**임이 시리즈에서 확립됨(참고: C14 553·A8 629, 양쪽 vu300 개시·vu300 정확히 36 동일).
  A8은 커널 캡처 미회수라 드롭 메커니즘 대조는 애초에 불가.
- 전략 라벨(C14=비관락 / A8=조건부)은 **둘 다 👤 운영자 직접 확정(2026-07-09)**. 기동 명령 파일증빙은 없고
  acquire 지문(C14 사다리 / A8 무사다리)이 보강.

## 4. HikariCP acquire 〔측정·서버측〕 — 병목 층 · 메커니즘 지문

> acquire = 커넥션 풀 대기 시간. 비관락은 join 처리 구간 내내 row 락을 잡아 풀 경합 → **사다리 + pending**,
> 조건부는 단발 원자적 UPDATE라 경합 없음 → **무사다리 + p50 <1ms 다수**. 전략을 가르는 결정적 지문.

## 5. (참고) 클라측 완료 p95는 판별 부적합 〔측정·파생〕

k6 클라측 완료 p95(드롭 제외)는 connecting 노이즈에 오염돼 **혼조** — 이 채널로 전략을 읽지 말 것.

| VU | C14 클라p95 | A8 클라p95 | (참고) 서버측은 §3 |
|---|---|---|---|
| 100 | **456.8** | 529.3 | ← 클라선 C14가 빠르게 보이나 |
| 400 | **2569.7** | 2710.9 | ← 서버측(§3)은 전부 A8 우세 |
| 700 | 3759.0 | **3621.0** | |

→ **클라측은 TCP 수립 지연이 지배 → 전략 판별은 서버측(§3)·acquire(§4)로만.**

## 6. 결론

| 층 | 승자 | 강도 |
|---|---|---|
| 락 정합성 | 동률(완벽) | success=10·5xx=0·유령409=0 양쪽 |
| **서버측 완료 p95** | **A8(조건부)** | **7/7 · 1.48~2.52×** |
| **서버측 완료 p50** | **A8(조건부)** | **7/7 · 1.28~2.09×** |
| **acquire p95** | **A8(조건부)** | **8/8 · 1.75~3.68×** |
| acquire p50 | A8(조건부) | 7/8 (vu20 노이즈 예외) |
| 드롭/커널 | 무관(비교 생략) | t3.micro TCP 천장·전략무관 |

**조건부(원자적 UPDATE)가 병목 층과 서버측 처리시간에서 전 구간 우세.** 정본 통제쌍(A1↔C7·C12↔A5·C13↔A6)은 아니지만
같은 밤·같은 구성·동일 실행순의 보조 비교로서 **조건부 우위를 독립 재확인**한다.
단 A8 커널 미회수로 드롭 메커니즘 대조는 빠져 있고, C14 vu20 서버측은 baseline0 근사라 제외했다.
