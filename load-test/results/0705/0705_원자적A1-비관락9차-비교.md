# 원자적 UPDATE(A1) vs 비관락 9차(C9) 비교 — 그리고 이 비교가 말해줄 수 있는 것의 한계

> **결론 먼저**: 표면 수치로는 **C9(비관락)이 A1(원자적)보다 무드롭 구간 완료 p95가 전 구간 15~42% 낮다.** 그러나 같은 비관락인 C7은 같은 표에서 A1보다 전 구간 **높았다**(느렸다). 같은 전략(C7↔C9)끼리 500~700ms 차이 나는 판에서 세션이 다른 A1↔C9의 p95 우열은 **전략 신호가 아니라 세션 상태(JVM 예열) 신호다.** 전략 우열의 정본은 여전히 **같은 밤 통제 비교 A1↔C7(원자적 우세)** 하나뿐이고, 이 문서의 A1↔C9 비교는 그것을 뒤집지 못한다 — 뒤집는 것처럼 보이는 게 이 문서의 핵심 발견이다.

> 출처 라벨: **〔측정〕** k6 summary.json 원값 + raw JSON 파싱(본 세션 동일 파서) · **〔파생〕** 원값 계산 · **〔추정〕**·**〔분석〕** §6~§7에 격리.
> ⚠️ A1 raw 주의: vu300·vu500은 2회 실행. raw 스트림은 **재런만** 보존(409 분해·볼리 분석은 재런 기준), summary는 첫 런·재런 각각 존재.

## 1. 측정 조건 — 애초에 대등하지 않다 〔측정〕

| 항목 | A1 (원자적 UPDATE) | C9 (비관락 9차) |
|---|---|---|
| 일시 (KST) | 07-04 21:21~21:35 밤 | 07-05 14:51~14:59 낮 |
| 기저 RTT (vu20~50 connecting) | **23.7~26.0ms** | **11.7~12.4ms (절반)** |
| 서버 도착 폭 (vu500 HTTP 시작 전폭) | 0.46s | 0.30s |
| JVM 상태 | 스윕 첫 런 워밍업 감속 있음 (vu20 성공 avg 366ms) | C8 스윕으로 예열 (vu20 성공 avg 126ms, 감속 없음) |
| listen backlog | 256 | 256 ("syn큐 올리" 무효 — 9차 보고서 §8) |
| 재런 | vu300·vu500 각 2회 | 없음 |

- **네트워크는 C9 쪽이 서버에 더 가혹했다** (RTT 절반 → 버스트가 더 원형으로 도착). **JVM은 C9 쪽이 더 유리했다** (예열 완료). 두 교란이 반대 방향이 아니라 각각 다른 지표(드롭↔지연)를 오염시킨다 — §6.

## 2. 정합성 — 양쪽 만점, 차이 없음 〔측정〕

| | A1 (10런) | C9 (7런) |
|---|---|---|
| join_success = 10 정확 | 전 런 ✅ | 전 런 ✅ |
| 응답 레벨 정원 초과 | 0 | 0 |
| join_conflict (CR023) | 0 | 0 |
| 5xx | 0 | 0 |

- 원자적 UPDATE의 단일 쿼리 경로도, 비관락의 행 락 직렬화도 500~700-way 경합에서 정원을 정확히 지켰다. **정합성으로는 두 전략을 가를 수 없다.**

## 3. 드롭 — 차이는 있지만 전략 신호가 아니다 〔측정→파생〕

| VU | A1 드롭 | C9 드롭 |
|---|---|---|
| 300 | 3 (첫 런) · 0 (재런) | 34 |
| 400 | 0 | 131 |
| 500 | 138 (첫) · 230 (재) | 160 |
| 700 | 218 | (미실행) |

- 표면상 "원자적이 드롭에 강해 보이는" 배치다. 그러나 드롭 개시 VU는 4세션에 걸쳐 **전략이 아니라 기저 RTT 순서**를 따랐다: 41ms(비관락 C6)→0건 · 25ms(원자적 A1)→vu500 · 12ms(비관락 C7·C9)→vu300 (`0705_비관락6-7-9차-비교.md` §1·§6).
- 드롭 미시 구조는 양쪽 동일 메커니즘: 초입 RST 볼리, 희생자는 connecting 최상단(늦게 수립된 커넥션), 에러 전량 `read: connection reset by peer`, ListenOverflows 0(A1 날 서버 실측). 차이 하나 — **볼리 폭**: C9 68~120ms의 단발 볼리 vs A1 vu500 797ms·vu700 3,052ms의 다단 볼리 〔측정·raw〕. 〔추정〕 RTT가 길수록 재전송·쿠키 재발급 주기가 볼리를 여러 파로 쪼갬.

## 4. 응답시간 — 표면 수치와 그 함정 〔측정〕

### 4-1. 무드롭 공통 구간 (vu20~200) 완료 p95 — 3자 병기

| VU | A1 (원자적, 07-04 밤) | **C9 (비관락, 07-05 낮)** | C7 (비관락, 07-04 밤) |
|---|---|---|---|
| 20  | 416   | **243** | 742 |
| 50  | 494   | **318** | 674 |
| 100 | 588   | **502** | 799 |
| 200 | 1,103 | **840** | 1,437 |

- A1↔C9만 보면 "비관락 승"(−15~−42%). A1↔C7만 보면 "원자적 승"(−300~−330ms). **C7↔C9는 같은 전략인데 2~3배 차이.** 세 값이 동시에 참이려면 결론은 하나 — **세션 간 절대 p95는 전략이 아니라 세션 상태를 재고 있다.**

### 4-2. 성공(201) 경로 〔측정〕

| VU | A1 avg / p95 | C9 avg / p95 |
|---|---|---|
| 20  | 366 / 404 (워밍업) | 126 / 192 |
| 50  | 144 / 190 | 125 / 184 |
| 100 | 118 / 161 | 135 / 208 |
| 200 | 338 / 362 | 167 / 218 |
| 300 | 183 / 219 (첫) · 225 / 319 (재) | 133 / 182 |
| 400 | 156 / 182 | 188 / 239 |
| 500 | **499 / 825 (첫)** · 251 / 269 (재) | 177 / 221 |
| 700 | 200 / 230 | — |

- 양쪽 다 "승자는 빠르다" 절연이 성립하되, 예외가 하나씩 아닌 A1에만 둘 있다: vu200(avg 338 — 앞뒤 118·183 대비 돌출)과 **vu500 첫 런(p95 825ms — 전 세션·전 런 통틀어 워밍업 제외 유일한 성공 경로 500ms 초과)**. vu500 첫 런은 드롭 138과 같은 창이다. 〔추정〕 원자적 경로도 수립층 폭풍(쿠키/재전송 볼리)과 겹치면 성공 응답까지 흔들린다 — 단발 사례라 일반화 불가.
- C9의 성공 경로는 전 런 p95 182~239ms로 평탄 (VU 25배 무반응).

## 5. 이 비교로 말할 수 있는 것 / 없는 것 〔분석〕

**말할 수 있다:**
1. 정합성은 두 전략 모두 만점 — 500-way 경합까지 정원 보증 관점에선 무승부.
2. 드롭 메커니즘은 전략 불문 동일(수립층 RST) — 전략 선택으로 리셋을 줄일 수 없다.
3. 성공 경로 절연은 양쪽 다 성립하나, 관측된 흔들림(성공 p95 825ms)은 A1 쪽에서 1회 나왔다 (드롭 볼리와 동시창, 단발).
4. 세션 간 절대 p95 비교는 전략 신호를 전달하지 못한다 — 같은 전략끼리(C7↔C9) 벌어진 폭이 전략 간(A1↔C7) 폭보다 크다.

**말할 수 없다:**
1. "비관락이 원자적보다 빠르다" (A1↔C9 표면 수치) — 세션 상태 교란. 반대 방향의 같은 밤 통제 비교(A1↔C7, 원자적 우세)가 여전히 정본이다.
2. "원자적이 드롭에 강하다" (vu400 0건 vs 131건) — RTT 교란. 4세션 곡선이 이미 기각.

## 6. 공정 비교를 위한 액션 〔분석〕

1. **같은 세션 교차 측정의 재실행**: 같은 밤에 [워밍업 런 → 원자적 스윕 → 재기동+워밍업 런 → 비관락 스윕] 순서로 — A1↔C7 비교의 유일한 결함(워밍업 비대칭·재기동 직후 비관락)을 제거한 판. 재기동이 필수(전략 플래그 전환)이므로 **워밍업 런을 절차에 넣는 것이 핵심**.
2. 드롭 비교는 지표에서 제외 유지 (7차 §9.7 · 6-7-9차 비교 §6 재확인).
3. 👤 전략 플래그(`--lock-strategy`)의 서버 기동 로그 증빙 — A1·C9 모두 미확보 상태로 이월 중.
